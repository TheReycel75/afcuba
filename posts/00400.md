# Google dice adiós a las contraseñas: así funciona el método que las sustituye  

Las contraseñas son el único método de protección en Internet en combinación con la autenticación en dos pasos si previamente la hemos activado, si no, la única barrera que impide a los amigos de lo ajeno acceder a nuestras cuentas es una contraseña.

Crear contraseñas seguras con muchos número, letras y signos está muy bien, sin embargo, cuando esta se filtra, no sirve absolutamente para nada, sino tenemos activada la función de verificación 2 pasos, función que nos envía una notificación con un código que debemos introducir en la web a la que queremos acceder.

El problema es que muchos son los usuarios que no utilizan la autenticación de doble factor para proteger sus cuentas y, como no hay nada absolutamente seguro en Internet, las grandes compañías han creado diferentes métodos para que nos olvidemos por completo de las contraseñas.

#### ¿Cómo puedo acceder a un servicio sin una contraseña?

La solución pasa por utilizar un dispositivo móvil o de escritorio para autorizar la conexión y donde previamente nos hemos identificado y se llama llaves de acceso. Las llaves de acceso nos permiten iniciar sesión de forma segura en una cuenta de Google utilizando dispositivos biométricos para identificar la nuestra huella digital, cara o un patrón, utilizando el [código PIN de Windows](https://www.softzone.es/windows/como-se-hace/restablecer-pin-acceso-windows-10/), o una llave de seguridad de hardware.

Google lanzó la función llaves de acceso (passkeys en inglés) hace varios meses y desde entonces ha estado en fase de prueba con un éxito muy elevado entre los usuarios, lo que los ha llevado al gigante de las búsquedas a ofrecerla como método predeterminado de identificación para todos los productos de la compañía.

De esta forma, la próxima vez que tengamos que iniciar sesión en una página web o aplicación utilizando una cuenta de Google, esta nos pedirá la correspondiente llave de acceso, aunque de momento también estará la posibilidad de utilizar la contraseña de toda la vida, para los usuarios que tarde más tiempo en utilizar este nuevo método.

#### Cómo crear una llave de acceso de Google

Si tenemos un dispositivo Android, no será necesario crear una llave de acceso ya que, con tan solo iniciar sesión, esta se crea automáticamente en el dispositivo. De esta forma, cuando queramos acceder a los productos de Google utilizando otro dispositivo, en nuestro dispositivo Android recibiremos una notificación invitándonos a aprobar la conexión.

![](https://images.weserv.nl/?url=https%3A%2F%2Fwww.softzone.es%2Fapp%2Fuploads-softzone.es%2F2023%2F10%2Fllave-acceso-google.jpg&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

Para poder aprobar esta notificación, debemos **desbloquear el acceso a nuestro móvil** utilizando el rostro, la huella dactilar o un código PIN o patrón. Si no tenemos esa información, no podemos desbloquear el acceso por lo que tampoco podremos aceptar el inicio de sesión.

Para crear una llave de acceso a nuestras cuentas de Google, debemos visitar el siguiente [enlace](https://myaccount.google.com/signinoptions/passkeys) utilizando los datos de nuestra cuenta de Google. Si tenemos algún dispositivo Android, se mostrará en la parte inferior. Si no es así, y queremos crear una nueva llave, pulsamos en **Crear llave de acceso**.

![](https://images.weserv.nl/?url=https%3A%2F%2Fwww.softzone.es%2Fapp%2Fuploads-softzone.es%2F2023%2F10%2Fllave-acceso-google-2.jpg&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

A continuación, nos invitará a utilizar el dispositivo que estamos utilizando o cualquier otro como llave de acceso o utilizar cualquier otro que ya se encuentre asociado a nuestra cuenta de Google. Si pulsamos en **Continuar** utilizando el dispositivo donde nos encontramos, se nos pedirá utilizar el método de protección que estemos utilizando, ya sea el código PIN, la huella o nuestro rostro.

![](https://images.weserv.nl/?url=https%3A%2F%2Fwww.softzone.es%2Fapp%2Fuploads-softzone.es%2F2023%2F10%2Fllave-acceso-google-3.jpg&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

Finalmente, si hemos introducido correctamente el PIN, la huella, rostro entre otros, se mostrará el equipo que se utilizará como llave de acceso para desbloquear el acceso a nuestra cuenta.

![](https://images.weserv.nl/?url=https%3A%2F%2Fwww.softzone.es%2Fapp%2Fuploads-softzone.es%2F2023%2F10%2Fllave-acceso-google-4.jpg&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)
