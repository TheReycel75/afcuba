# Cómo instalar aplicaciones de Windows en Android  

Podríamos decir que Android supuso una revolución a la era moderna similar a lo que fue Windows en su momento. De hecho, el sistema operativo de Google superó hace unos años al de Microsoft como el más utilizado en entornos domésticos. A pesar de esto, los ordenadores siguen siendo territorio de Redmond y muchas veces no es posible **usar aplicaciones de Windows sin un ordenador**.

Si bien es común usar aplicaciones de Android en dispositivos Android y aplicaciones de Windows en sistemas operativos Windows, debes de saber que existen programas que te permiten **instalar aplicaciones android en windows**. Lo que muchos desconocen es que también es posible hacerlo a la inversa, es decir **instalar aplicaciones de Windows en Android**.

#### ¿Se pueden instalar aplicaciones Windows en Android?

Si, para ello sigue leyendo este artículo donde te vamos a explicar como instalar aplicaciones de Windows en un móvil Android. Específicamente lo haremos con [Wine](https://www.winehq.org/) que es un proyecto de código abierto que permite **ejecutar aplicaciones de Windows en otros sistemas operativos** como MacOS o Linux.

[Wine](https://www.winehq.org/) es compatible con Android desde hace más de un año y podemos **ejecutar aplicaciones de Windows en teléfonos Android**. Ahora se ha actualizado a la versión 7, mejorando muchas de sus funciones, merece la pena que lo pruebas y puedas usar tus aplicaciones de Win en Android.

#### ¿Qué aplicación debo descargarme para instalar aplicaciones WIndows en Android?

La aplicación es Wine y puedes [descargar la APK Wine en la versión adecuada para nuestro dispositivo](https://dl.winehq.org/wine-builds/android/) (normalmente ARM) e instalarla en nuestro móvil. No es un emulador ni nos permite **instalar Windows en nuestro Android** pero podemos **instalar aplicaciones windows en el móvil**.

#### Para usar aplicaciones Windows en Liunux ten en cuenta estas recomendaciones

Lo primero que recomendamos es hacer todo el proceso un ratón y/o teclado conectado a nuestro móvil Android, y también resulta recomendable utilizar un monitor externo. De hecho, la versión 7 de Wine incluso permite el uso de múltiples monitores externos simultáneos, aunque esto no sea una funcionalidad de Android en si si no un añadido de Wine.

#### Wine para Android trae mas de 7000 cambios para usar .exe en Android

La última versión de Wine ha añadido más de 7000 cambios entre los que destacan el soporte para gráficos Vulkan 1.1 y la implementación de XAudio2 . Si estás interesado en este tema, te recomendamos que visites la página del proyecto, que tiene una sección bastante completa de [Preguntas y respuestas](https://www.winehq.org/help).
