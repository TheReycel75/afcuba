# Los 75 mejores prompts para Google Gemini  

En el post de hoy vamos a repasar algunos de los mejores prompts que podemos emplear con Gemini, tanto en su versión gratuita como de pago. Recuerda que puedes acceder a Gemini desde el navegador en gemini.google.com, o instalando la app oficial a través de la Play Store de Android.

#### Prompts básicos para Gemini

Comenzamos con algunos de los prompts más esenciales. Estos prompts se suelen emplear en mayoría de chats de inteligencia artificial con bastante buen resultado.

Actúa como si fueras un experto en X.

Presenta la información en una tabla.

Explícame X, pero no escribas o menciones el tema Y.

Quiero una respuesta corta y concisa. Solo explícame X.

Eres un X. (usa este prompt para usar Google Gemini como una herramienta. Por ejemplo, un traductor, una calculadora, un conversor de divisas, etc.)

Escribe para este público objetivo.

Escribe una explicación larga.

Crea una lista de XYZ.

Hazme un plan detallado para XYZ.

Dame instrucciones paso a paso para XYZ.

Dame instrucciones para llegar del punto A al punto B, y muéstrame fotografías de los puntos más importantes del recorrido.

Recomiéndame 3 videos de YouTube que expliquen el tema X en profundidad.

#### Prompts para el análisis de imágenes

Recuerda que Gemini es una IA multimodal, lo que significa que también podemos enviarle imágenes y pedirle que las analice. Tan solo pulsa sobre el icono de imagen que verás junto a la burbuja de introducción de texto.

¿Qué raza de perro/gato/animal aparece en esta imagen?

¿Qué tipo de planta es la que aparece en esta imagen?

Escribe un prompt preciso y detallado que sirva para generar una imagen lo más parecida posible a la imagen que te acabo mostrar. (Utiliza este prompt para hacer ingeniería inversa y averiguar el prompt utilizado para generar una imagen que te gusta y poder replicarla)

¿En qué lugar se tomó esta fotografía?

Qué receta se utilizó para elaborar el postre que aparece en la imagen?

Invéntate una historia corta a partir de la escena representada en esta imagen.

Muéstrame imágenes de vehículos similares al que aparece en esta foto.

¿A qué película pertenece este fotograma?

#### Prompts para estudiantes

Proporciona 10 preguntas de opción múltiple sobre (asignatura) para un estudiante de X grado.

Vuelve a escribir mi redacción para que sea más interesante de leer.

Investiga el siguiente tema y genera una lista de 5 puntos clave.

Te voy a presentar un problema, y quiero que lo resuelvas mientras me lo explicas paso a paso. Éste es el problema:

Describe claramente la física de partículas (o cualquier otro tema).

Genera un esquema para una redacción sobre (tema).

Dame una lista de referencias que pueda usar para una redacción sobre (tema).

En la novela/libro X, ¿por qué el autor…?

¿Cuál sería el mejor enfoque para escribir un artículo sobre (tema)?

Genera una lista de fuentes para leer más sobre (tema).

#### Prompts sobre programación y desarrollo web

Actúa como un desarrollador de (nombre de tecnología). Escribe un código / programa para realizar X tarea.

Escribe el código para una extensión de Chrome que (función).

Escribe un código en JavaScript para (objetivo).

Completa este código de (lenguaje) para analizar (formato de archivo) y extraer (información): (fragmento de código).

Rellena el código de (lenguaje) que falta para implementar (tarea) para la siguiente función: (fragmento de código).

Localiza cualquier error lógico en el siguiente fragmento de código de (lenguaje): (fragmento de código).

Identifica posibles problemas de rendimiento en este fragmento de código de (lenguaje): (fragmento de código).

Prompts sobre música

Simplifica los acordes de la canción X.

Enséñame los acordes y la letra de la canción X.

¿Qué significa la letra de la canción X?

Reescribe la canción X para que trate sobre el tema Y.

Sube 2 tonos la canción X.

Traduce la letra de la canción X al español.

Diseña un paisaje sonoro para un videojuego sobre el tema X.

Diseña una banda sonora única que refleje las emociones X.

¿Qué pedal de efectos utiliza el guitarrista del grupo X?

  

#### Prompts para escritores, redactores y creadores de contenido

  

Haz un esquema para una publicación en mi blog sobre XXX usando palabras clave relacionadas basadas en los datos de búsqueda de Google.

Sugiere 5 títulos atractivos para un artículo de mi blog sobre XXX.

Escribe una guía completa sobre XXX.

Escribe un post para mi blog sobre XXX.

Genera cinco sinónimos para la palabra XXX.

¿Cuál es el mejor enfoque para crear contenido en el nicho XXX?

¿Cuáles son algunas de las formas más creativas de reutilizar publicaciones de blog antiguas?

Elige cinco palabras clave para un post de mi blog que se titule «XXX».

¿Qué temas debo incluir en las publicaciones de mi blog para posicionar en Google para la palabra clave XXX?

Quiero que actúes como un editor SEO y redactor. Revisa y analiza el siguiente texto, y optimízalo para la palabra clave XXX.

Escribe 5 publicaciones para Twitter sobre XXX.

Escribe un guion para un video de 5 minutos sobre XXX.

¿Qué tipos de publicaciones consiguen un mayor nivel de engagement entre los usuarios en las redes sociales?

Prompts para negocios y emprendedores

Crea una lista de 10 ideas de negocios de bajo coste que se pueden iniciar con una inversión mínima.

Proporcione 7 ejemplos de negocios exitosos en X industria.

Resume los componentes clave de un plan de negocios para un negocio de \[industria/tipo de negocio\].

Te daré una lista de tareas que debo completar y me gustaría que las pusiera en un cronograma para el día. Mi día comenzará a las 8:30 am y terminará a las 6 pm.

Eres un agente de atención al cliente experimentado cuya prioridad es resolver problemas y hacer felices a los clientes. Lee y analiza este correo electrónico de queja del cliente \[pega el texto de la queja del cliente\]. Responde a este correo electrónico para pedir disculpas porque no hemos cumplido con sus expectativas y pregunta qué podemos hacer para solucionarlo. Sugiere remedios potenciales basados en los detalles de la queja.

Explica el uso de los fondos para una empresa de tipo X y cómo el negocio logrará ser rentable.

Describe las estrategias de marketing y ventas para un negocio de \[industria/tipo de negocio\].

Genera una lista de 7 casos de uso diferentes para X producto/servicio.
