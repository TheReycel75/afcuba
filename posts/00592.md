# Qué es el formato .XAPK y por qué es útil para instalar apps y juegos pesados en Android

Un APK (Android Application Package) es un archivo en el que está empaquetado una aplicación para Android. Básicamente es el archivo para [instalar las aplicaciones y juegos en Android](https://www.xatakandroid.com/tutoriales/como-instalar-aplicaciones-en-apk-en-un-movil-android). Sin embargo **existen otros formatos en Android que también nos permiten instalar aplicaciones**. Hoy vamos a hablar de una extensión que algunas veces nos hemos encontrado y no es tan sencilla de instalar como lo son los .apk.

Se trata del **formato XAPK**, un nuevo estilo de archivo que permite también instalar aplicaciones y juegos en Android. No estamos ante un formato oficial como sí lo es el APK, pero es interesante conocerlo y ver cómo puede sernos útil.

#### Qué es el formato .XAPK

Si intentamos **instalar directamente un archivo con el formato XAPK nos dará error**. Esto es básicamente porque el instalador por defecto de Android no entiende este formato ni puede extraer correctamente la información que hay dentro de él.

¿Qué ocurre entonces? ¿Es seguro instalar un archivo .XAPK? Sí. Principalmente estamos ante una alternativa al APK. De hecho, **un archivo .XAPK en realidad es simplemente un archivo .APK más los datos OBB adicionales** necesarios para que funcione correctamente el juego o la aplicación. Es decir, es un archivo comprimido que contiene el APK original más unos archivos de datos extra.

El formato .XAPK es un equivalente al .APK pero engloba varios archivos, normalmente paquetes asociados a la aplicación original.

Normalmente estos archivos extra se descargan a través de la aplicación, pero en algunos casos **nos interesa tenerlos ya en el móvil directamente**. Esto puede ocurrir por muchos motivos, pero lo habitual es que el propio juego o aplicación esté limitado y entonces no nos dejen descargar estos datos necesarios.

Tampoco es extraño que estos **datos se encuentren de manera independiente, por lo que tendríamos un archivo .OBB**. Datos de caché como por ejemplo mapas explorados, niveles conseguidos o enemigos derrotados, pero también mapas relacionados con determinados mercados, habilidades reservadas a ciertos usuarios o información adicional que no se encuentra integrada dentro del propio APK.

#### Cómo instalar archivos .XAPK en Android

Las propias páginas que ofrecen las aplicaciones .XAPK suelen tener un instalador especializado.

Para instalar un archivo .XAPK en Android necesitaremos un **instalador especializado**. También previamente deberemos activar la opción de orígenes desconocidos. Una vez hecho esto, para proceder a instalar este archivo descargaremos un instalador de paquetes .XAPK como los que ofrecen [APKPure](https://apkpure.com/xapk.html) o [Uptodown](https://uptodown-android.uptodown.com/android), dos páginas webs de descarga de aplicaciones Android que acostumbran a ofrecer también aplicaciones .XAPK.

En vez de abrir el archivo .XAPK con el instalador de paquetes por defecto de Android, deberemos **ir a la aplicación especializada y seleccionar el archivo**. Una vez lo abramos, el proceso de instalación será equivalente al habitual. Con la diferencia que una vez hayamos instalado el archivo XAPK tendremos tanto el original APK, como los datos OBB ya añadidos.

Es importante también señalar que **los archivos XAPK tienen un tamaño mucho mayor al de los APK**, ya que contienen habitualmente más cantidad de datos información. Esto también se apreciará a la hora de instalarlo, ya que el tiempo será mayor.

#### Qué tipo de aplicaciones utilizan este formato

Si os habéis encontrado con un archivo XAPK es seguramente porque queréis **descargar fuera de Google Play una aplicación que no está disponible todavía en vuestra región**. Es algo muy habitual ya que muchos juegos o aplicaciones primero se lanzan en el país de origen y después progresivamente van llegando a otros mercados.

Ocurrió recientemente con el [PUBG Mobile](https://www.xatakandroid.com/juegos-android/pubg-mobile-primeras-impresiones-las-batallas-multijugador-con-mas-accion-llegan-a-android), un **juego que necesitaba de datos OBB concretos para poder funcionar**, ya que se trata de un título multijugador. En este caso, si teníamos el archivo .XAPK del PUBG Mobile necesitábamos descargar un instalador de paquetes especializado para poder abrirlo.

Lo más habitual es que el formato .XAPK se utilice para juegos pesados que necesitan paquetes adicionales para funcionar en determinadas regiones.

Esperamos que con este pequeño tutorial hayáis aprendido qué son los archivos XAPK y cómo podéis instalarlos en caso que tengáis entre manos una aplicación o juego con este formato.
