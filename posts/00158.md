# Dale a Windows un toque personal: cambia el tipo de letra por defecto por otra  

Con el paso de los años el aspecto de la interfaz del sistema operativo de Microsoft ha cambiado y mejorado de manera ostensible. Aquí encontramos multitud de elementos gráficos que forman parte de la misma y que en ocasiones podemos cambiar en Windows, como sucede con el **tipo de letra o fuente**.

Hay que tener en consideración que Microsoft establece una fuente predeterminada que se utiliza en la mayoría de los apartados que forman parte de la **interfaz de Windows**. Pero este no es el único elemento que hace de nuestro sistema un tanto original. Aquí también entran en juego otros como los diferentes menús, los iconos o las ventanas. A continuación, os vamos a mostrar un método de personalización del sistema operativo que no es tan habitual como el cambio de fondo de escritorio, por ejemplo.

En concreto nos referimos a la posibilidad de cambiar el tipo de letra o fuente por defecto que se van a utilizar en diferentes apartados de este sistema de Microsoft. Para ello vamos a utilizar un útil software que nos servirá de mucha ayuda para estas tareas que os comentamos. Y es que tener en consideración que multitud de usuarios de Windows prefieren trabajar con un software adaptado a sus necesidades o gustos.

Para ello la propia Microsoft nos ofrece multitud de funciones integradas para llevar a cabo este tipo de cambios. Igualmente encontramos algunas soluciones software que nos serán de mucha ayuda en estas tareas de personalización, como es el caso que nos ocupa. Además, este es un programa gratuito y muy sencillo de utilizar para así modificar un apartado tan importante como las fuentes que utilizará Windows por defecto, **Advanced System Font Changer**.

#### Cambia el aspecto de Windows con Advanced System Font Changer

Como os podéis imaginar esta modificación cambiará de manera radical el aspecto de la interfaz de Windows. Además, estos cambios los podremos llevar a cabo de manera sencilla tantas veces como deseemos. Lo primero que debemos saber es que de forma predeterminada Windows utiliza la fuente llamada **Segoe** en la mayoría de los apartados que forman parte del sistema operativo.

Por tanto, una vez descarguemos el programa [Advanced System Font Changer](https://www.wintools.info/index.php/advanced-system-font-changer#google_vignette), la primera vez veremos un listado con varias secciones de Windows y este tipo de letra establecido como predeterminado. Esto quiere decir que podremos modificar la fuente de todos ellos de manera sencilla e independiente desde la **interfaz de esta aplicación**.

![](https://images.weserv.nl/?url=https%3A%2F%2Fwww.softzone.es%2Fapp%2Fuploads-softzone.es%2F2023%2F05%2FAdvanced-System-Font-Changer.jpg&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

En un principio basta con que localicemos el apartado del sistema que nos interesa cambiar y pinchemos sobre la fuente predeterminada. En ese momento en **pantalla** aparecerá una nueva ventana en la que podemos desplegar un listado con las fuentes instaladas para seleccionar cualquier otra. Además, adicionalmente tendremos la posibilidad de modificar su tamaño y establecerla como negrita si así lo deseamos.

Como os podéis imaginar esto nos abre un amplio abanico de posibilidades a la hora de personalizar el **aspecto de la interfaz** del sistema operativo en su totalidad.

![](https://images.weserv.nl/?url=https%3A%2F%2Fwww.softzone.es%2Fapp%2Fuploads-softzone.es%2F2023%2F05%2Ffuentes-programa-windows.jpg&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

Esto es algo que podremos repetir tantas veces como deseemos con los diferentes apartados o secciones del sistema operativo. Estos nos los ofrece Advanced System Font Changer en un principio. Asimismo, merece la pena reseñar que tenemos a la posibilidad de **crear diferentes perfiles.** Cada uno con sus propias fuentes, para así cambiar entre los mismos siempre que lo deseemos. Al mismo tiempo tendremos la posibilidad de importar y exportar dichos perfiles si utilizamos esta misma aplicación para personalizar Windows en diferentes equipos.

Dependiendo del tipo de uso que hagamos del sistema operativo, podremos utilizar un perfil u otro personalizando los tipos de letra predeterminados.
