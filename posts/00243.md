# Cómo reparar y extraer un archivo ZIP corrupto o invalido  

Los archivos comprimidos ZIP o RAR se corrompen muy fácilmente, ya que basta con que un bit o una pequeña porción de datos esté corrupta para que el sistema no los pueda **abrir, leer ni descomprimir el archivo**. En el caso de que estemos trabajando con Windows el error habitual suele ser algo así como “**_El fichero está dañado o es inválido_**”.

Aunque Windows ya permite crear y extraer archivos ZIP de forma nativa desde hace varios años, lo cierto es que si queremos reparar un ZIP corrupto no nos queda más remedio que optar por programas especializados. La mayoría de estos programas suelen ser de pago, pero también existen alternativas gratuitas bastante eficientes, y eso es precisamente lo que veremos en el post de hoy.

#### 6 programas gratuitos para reparar y descomprimir ficheros ZIP inválidos

Aunque hablamos de software gratuito, cabe aclarar que al tratarse de herramientas profesionales, algunas suelen funcionar bajo un modelo de tipo “shareware”. Es decir, que son gratuitas y 100% funcionales pero con alguna limitación (normalmente en el tamaño máximo del archivo a reparar).

### DiskInternals ZIP repair

DiskInternals es una compañía especializada en la recuperación de datos, y cuenta con una utilidad freeware llamada “ZIP repair” con la que podemos recuperar zips dañados. La aplicación dispone de un asistente que nos guiará durante todo el proceso: solo tenemos que seleccionar el archivos corrupto, una carpeta de destino, y el programa nos indicará qué parte del contenido se puede recuperar. Fácil de usar y bastante eficiente.

**[Descargar DiskInternals ZIP repair desde su web oficial](https://www.diskinternals.com/zip-repair/)**

Zip2Fix

Zip2Fix es una herramienta que recupera ZIPs dañados extrayendo los ficheros que están “sanos” (dejando los corruptos de lado) y volviéndolos a comprimir en un nuevo ZIP. Para ponerlo en marcha pulsamos sobre el botón de “Open”, seleccionamos el archivo ZIP/SFX dañado y el programa automáticamente comenzará a analizar el archivo en busca de todo lo que se pueda salvar.

Durante la instalación hay que tener cuidado de desmarcar las pestañas correspondientes para que no se nos instalen los típicos programas no deseados que suelen incluirse en este tipo de utilidades gratuitas (de algo tienen que vivir). Otra ventaja de Zip2Fix es que se trata de una herramienta portable, por lo que no es necesario instalarla en el equipo.

**[Descargar Zip2Fix desde su web oficial](http://leelusoft.altervista.org/zip2fix.html)**

### Object Fix Zip

Herramienta gratuita dedicada a la reparación de archivos ZIP. Cuenta con un asistente que nos guía durante todo el proceso: seleccionamos el archivo dañado, la ruta donde queremos guardar el archivo recuperado, realizamos un análisis y el programa intentará arreglar las partes dañadas. Entre sus funcionalidades disponibles, permite **extraer archivos de un ZIP con errores de CRC**, así **extraer los archivos de ZIPs que solo se han descargado parcialmente**.

Estamos ante una utilidad que dejó de actualizarse allá por 2015, lo que significa que probablemente tendrá problemas para solucionar los fallos o errores más modernos. En cualquier caso, es una opción más que valida si no conseguimos resultados positivos con ninguna otra aplicación.

**[Descargar Object Fix Zip desde su web oficial](http://www.essentialdatatools.com/products/objectfixzip/)**

### WinRAR

El famoso WinRAR también cuenta con una herramienta de reparación para archivos ZIP y RAR. Primero abrimos WinRAR, cargamos el archivo con error y vamos hasta el menú “_Herramientas -> Reparar archivo_”. El fichero corregido aparecerá en la carpeta que nosotros elijamos,con el mismo nombre que el original pero con el prefijo “_rebuild_”.

**[Descargar WinRAR desde su web oficial](https://www.winrar.es/descargas/winrar)**

### WinZip

WinZip es otra conocida herramienta para comprimir/descomprimir archivos que también permite reparar ZIPs dañados. Sin embargo, debemos tener en cuenta que la aplicación ahora es de pago, por lo que debemos descargar la versión de prueba gratuita que nos permitirá hacer uso de ella durante 21 días.

El proceso de reparación es más complejo que el de otras aplicaciones similares, ya que requiere ejecutar comandos desde la ventana de terminal de Windows:

*   Primero, descarga la versión de prueba de WinZip [desde su web oficial](https://www.winzip.com/es/product/winzip/). Descarga también el complemento [WinZip Command Line](https://www.winzip.com/en/download/command-line/) desde la web de WinZip e instala ambas aplicaciones en tu PC.
*   Abre el explorador de archivos de Windows y navega hasta la carpeta donde se encuentra el ZIP dañado. Haz clic derecho con el ratón en una zona libre del explorador y selecciona «Abrir en terminal».
*   Dentro de la ventana de terminal lanza el siguiente comando para reparar el archivo ZIP dañado. Sustituye la variable «archivodañado.zip» por el nombre real de tu archivo dañado:
    *   **«C:\\Program Files\\WinZip\\wzzip» -yf archivodañado.zip**

![](https://images.weserv.nl/?url=https%3A%2F%2Felandroidefeliz.com%2Fwp-content%2Fuploads%2F2023%2F07%2FComo-reparar-un-ZIP-danado-con-WinZip-01.jpg&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

Una vez finalizado el proceso de reparación, vuelve a la carpeta donde se encuentra el ZIP dañado y encontrarás la versión reparada de ese archivo.

### PowerArchiver

Para sanear ZIPs con error con el compresor de PowerArchiver abrimos la aplicación y vamos hasta “_Tools -> Repair ZIP_”. Desde aquí seleccionamos el fichero corrupto y pulsamos el botón de “_Start_” para que comience la magia. El archivo recuperado se guardará automáticamente en la misma ruta que el original, con el mismo nombre incluyendo el sufijo _“\_PAFixed_”. Por cierto, PowerArchiver está disponible tanto para Windows como para macOS.

**[Descargar PowerArchiver desde su web oficial](https://www.powerarchiver.com/download-powerarchiver/)**

#### 4 herramientas premium para reparar ZIPs dañados o corruptos

Si tenemos un ZIP que no se abre porque está dañado y ninguna de las aplicaciones gratuitas que hemos mencionado hasta ahora nos sirven, es hora de pasar a mayores. Para ello vamos a recomendar 4 programas de reparación de archivos comprimidos. Hablamos de herramientas de pago, aunque todas ellas cuentan con una versión de prueba gratuita que podemos descargar y probar en nuestro PC.

### Kernel for ZIP File Recovery

Una de las mejores aplicaciones de pago para recuperar ZIPs dañados. Cuenta con una interfaz que **permite añadir varios archivos ZIP de una sola vez** para ser analizados. Una vez añadido el archivo el sistema lo analiza automáticamente mostrando los archivos comprimidos que contiene en su interior. Cuenta con un alto ratio de reparaciones exitosas. Actualmente tiene una versión de prueba gratuita y un precio de 29 dólares para la versión de pago (una licencia para el hogar).

**[Descargar Kernel for ZIP File Recovery desde su web oficial](https://www.nucleustechnologies.com/Download-ZIP-File-Repair-Software.php)**

### DataNumen ZIP Repair

Herramienta premium para la recuperación de ZIPs dañados. Compatible con archivos protegidos por contraseña, permite añadir varios archivos al mismo tiempo. Una vez consigue arreglar un archivo guarda una copia con otro nombre para no sobrescribir el original. Cuenta con una interfaz bastante agradable y muy fácil de usar. Disponible versión de prueba gratuita. La versión premium tiene un precio de 49,95 dólares (una licencia).

**[Descargar DataNumen ZIP Repair desde su web oficial](https://www.datanumen.com/zip-repair/)**

### ZipRecover

Otra herramienta de lo más interesante para recuperar datos de archivos ZIP corruptos. Ofrece soporte para ZIPs protegidos con contraseña. Su funcionamiento es bastante diferente al resto de utilidades similares, ya que no crea una copia «sana» del ZIP, sino que extrae su contenido directamente en la carpeta que indique el usuario. Disponible versión de prueba gratis (la versión de pago tiene un precio de 48,34 dólares).

**[Descargar ZipRecover desde su web oficial](https://www.ziprecover.com/)**

![](https://images.weserv.nl/?url=https%3A%2F%2Felandroidefeliz.com%2Fwp-content%2Fuploads%2F2021%2F06%2FAplicaciones-para-reparar-ZIPs-danados-o-corruptos-003.jpg&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

### Sysinfo ZIP Repair Tool

Herramienta premium de reparación de archivos ZIP corruptos o inaccesibles. Cuenta con una interfaz de lo más intuitiva que nos va guiando durante el proceso de recuperación. Permite 2 modos de análisis: uno básico para hacer una reparación rápida y un modo avanzado más minucioso para aquellos archivos comprimidos con daños más severos.

Muy útil para recuperar y extraer ZIPs divididos en varias partes con el clásico error «Cannot open file: not a valid archive» (_No se puede abrir el fichero: archivo no válido_). Ofrece versión de prueba gratis. La versión premium tiene un precio de 34 dólares (una licencia).

**[Descargar Sysinfo ZIP Repair Tool desde su web oficial](https://www.sysinfotools.com/recovery/zip-recovery.php)**
