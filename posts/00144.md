# Rufus 4.1, nueva versión para crear USB autoarrancables  

Rufus 4.1 es la nueva versión de una de las mejores aplicaciones para crear **unidades externas auto arrancables** para instalación de sistemas operativos, pruebas de software o resolución de problemas.

[Un tipo de software](https://www.muycomputer.com/2022/03/14/unidad-usb-de-arranque/) muy útil que a buen seguro tienes en tu arsenal de herramientas y que permite crear unidades USB de arranque con Windows, Linux y otros sistemas operativos. Las novedades de la versión incluye la creación de unidades de MS-DOS a través de la descarga de archivos binarios de Microsoft o solución para una incompatibilidad UEFI:NTFS con la plataforma Windows Dev Kit 2023, como aspectos destacados.

Cambios menores para una aplicación ya sobresaliente (para nuestro gusto **la mejor a la hora de manejar instalaciones de Windows**) que permite descargar imágenes ISO directamente desde Microsoft, lo que convierte a Rufus en un programa todo en uno para instalaciones limpias y el mantenimiento de sistemas operativos en PCs.

Además, tiene algunos ases adicionales bajo la manga a la hora de crear unidades de instalación para Windows 11 y que [superan imposiciones de Microsoft](https://www.muycomputer.com/2023/01/09/rufus-supera-de-nuevo-el-bloqueo-de-microsoft-a-las-descargas-de-windows/) (algunas incomprensibles que penalizan su adopción) como la posibilidad de crear cuentas locales, deshabilitar BitLocker y otros como TPM y Secure Boot. También tiene la opción de crear el _windows para llevar_, Windows To Go.

Rufus 4.1 es software libre, gratuito y de código abierto. Está disponible [en su página web](https://rufus.ie/downloads/) y también en GitHub. Funciona para software de varias plataformas (Windows, Linux, FreeDos…), pero -en mi opinión después de más una década de uso- **es imbatible cuando tratamos con Windows**. y está especialmente recomendado si vamos a instalar el sistema operativo en máquinas con las nuevas UEFI y/o particiones GPT, porque no todas las herramientas alternativas son capaces de realizar el medio correctamente en este tipo de formatos.
