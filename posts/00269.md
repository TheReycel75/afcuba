# ¿Qué Es Un Archivo AVI? Para Qué Sirve Y Cómo Abrir Uno  

Un archivo AVI es un archivo de vídeo almacenado en el formato contenedor de medios Audio Video Interleave (AVI) **desarrollado por [Microsoft](https://www.microsoft.com/es-ve)**.

Almacena datos de vídeo y audio y puede codificarse en varios códecs, como DivX y XviD.

Los archivos AVI pueden ser abiertos por varios reproductores de vídeo, como Microsoft Movies & TV, Windows Media Player y Apple QuickTime Player, incluidos en los sistemas operativos correspondientes.

#### ¿Qué es un archivo AVI?

Los archivos AVI están relacionados principalmente con el paquete de películas y televisión de Microsoft. AVI (Audio Video Interleave) **es un formato de archivo de vídeo** desarrollado por Microsoft. Los archivos con la extensión AVI suelen utilizarse para almacenar películas que contienen múltiples secuencias de audio y vídeo y que pueden reproducirse localmente con programas como Media Player, Movies & TV, QuickTime o VLC.

Un archivo AVI contiene datos como cabeceras de archivo, vídeo comprimido/descomprimido, datos de audio y cambios de paleta. Cuando los archivos AVI se transfieren por la red, utilizan tipos MIME como video/avi, video/msvideo, video/vnd.avi o video/x-ms-video. Para codificar/decodificar datos multimedia en archivos AVI se utilizan códecs como XVID, Indeo, Cinepak, Uncompressed RGB, DivX y YUY2.

AVI **también se utiliza habitualmente para almacenar datos audiovisuales en algunos DVD**. AviSys, un antiguo programa utilizado por los observadores de aves, también utiliza archivos AVI para almacenar su base de datos de observadores de aves.

#### Características del formato AVI

*   Contiene material de vídeo de muy alta calidad.
*   Uno de sus principales inconvenientes es que el tamaño del archivo sigue siendo muy grande, lo que hace que el vídeo en este formato no sea adecuado para su publicación en Internet.
*   Puede ser reproducido por la mayoría de los reproductores, tanto en ordenadores Windows como Mac, siempre que se instalen los códecs de vídeo y audio adecuados para el tipo de reproductor.
*   En general, los códecs con mayor capacidad de compresión y una calidad razonablemente buena son DivX y XviD; suelen utilizarse para vídeos largos, como las películas.
*   Es un formato popular para conservar los vídeos originales creados con una cámara digital.

#### ¿Cómo funciona el formato AVI?

El formato AVI permite grabar un único flujo de vídeo y varios flujos de audio al mismo tiempo. Una de las principales características que diferencia a AVI de otros formatos es que el audio y el vídeo pueden guardarse en cualquier otro formato, como MP3 para el audio y DivX para el vídeo. Por eso AVI es un formato contenedor.

Ya hemos mencionado que el formato AVI soporta múltiples flujos de audio. ¿Por qué? Porque puede contener varias pistas de audio en diferentes idiomas. Dependiendo de las preferencias del usuario, el reproductor multimedia debe decidir qué flujo de audio reproducir.

#### ¿Cómo se forma el formato AVI?

Este formato de contenedor de audio y vídeo **está dividido en varias partes, llamadas chunks**, cada una de las cuales tiene un código de identificación específico, la llamada etiqueta Four CC. El formato AVI suele estar dividido en dos trozos, pero a veces se puede añadir un tercer trozo si se desea:

*   **Primer chunks:** también se denomina cabecera, y su objetivo es describir la metainformación sobre el archivo, como el tamaño de la imagen de vídeo.
*   **Segundo chunk:** contiene los flujos de audio y vídeo.
*   **Tercer chunk:** es opcional y, si está presente, sirve como puntero a los chunks primero y segundo.

#### Programas para abrir y convertir archivos AVI:

### 1\. Microsoft Media Player (vídeo)

Media Player es un reproductor de vídeo y audio digital que viene con la mayoría de las versiones del sistema operativo Windows. Puede reproducir WMV, AVI, MP3, WMA y otros formatos de archivo. **Este formato de archivo está clasificado como vídeo**.

**_[Descargar Microsoft Media Player](https://support.microsoft.com/es-es/windows/obtener-el-reproductor-de-windows-media-81718e0d-cfce-25b1-aee3-94596b658287)_**

### 2\. VLC (vídeo) de VideoLAN

VLC es un reproductor multimedia multiplataforma que permite transferir, grabar y convertir archivos de audio y vídeo. **Dispone de una amplia biblioteca de códecs** para reproducir archivos AVI y muchos otros formatos de vídeo y audio. Este formato de archivo está clasificado como vídeo.

**_[Descargar VLC](https://www.videolan.org/vlc/index.es.html)_**

### 3\. AviSys (base de datos de observación de aves) - Jerry Blinn

AviSys es un programa de seguimiento de aves en peligro de extinción. El programa almacena su base de datos de observadores de aves en archivos AVI. Con los complementos de AviSys también puede catalogar mariposas (archivos BTR), libélulas (archivos DRG) y reptiles (archivos HRP). Este formato de archivo se clasifica como base de datos.

**_[Descargar AviSys](https://avisys.info/)_**

#### ¿Cómo abrir un archivo AVI?

Afortunadamente, los problemas más comunes con los archivos AVI pueden solucionarse sin necesidad de amplios conocimientos informáticos y, lo que es más importante, en tan sólo unos minutos. Hemos elaborado una lista para ayudarte a resolver los problemas con los archivos AVI.

### Paso 1: Descarga el reproductor de Windows Media

La causa más común de este tipo de problemas es la falta de un programa adecuado en tu sistema para manejar los archivos AVI. **La solución más obvia es descargar e instalar el Windows Media Player**, o uno de los siguientes programas: RealPlayer, TotalMedia Theatre o PowerDirector.

Una de las formas menos arriesgadas de descargar el software es utilizar los enlaces proporcionados por los distribuidores oficiales. Visita el sitio web del Reproductor de Windows Media y descargue el instalador.

### Paso 2: Actualiza el reproductor de Windows Media a la última versión

Si ya tienes instalado el Reproductor de Windows Media en tu sistema, pero sigues sin poder abrir correctamente los archivos AVI, **asegúrate de que tienes instalada la última versión** del Reproductor de Windows Media.

A veces, los desarrolladores de software introducen nuevos formatos en lugar de los ya soportados por las nuevas versiones de sus aplicaciones. Esta podría ser una de las razones por las que los archivos AVI no son compatibles con el Reproductor de Windows Media.

La última versión del Reproductor de Windows Media es compatible con versiones anteriores y puede admitir formatos de archivo compatibles con versiones anteriores del software.

### Paso 3: Combinar Windows Media Player con archivos AVI

Si el problema descrito en el paso anterior no se resuelve, empareja tus archivos AVI utilizando la última versión del Windows Media Player instalada en tu dispositivo. **El siguiente paso no debería ser difícil**. El procedimiento es sencillo y en gran medida independiente del sistema.

#### El procedimiento para cambiar el programa por defecto en Windows

*   _Haz clic con el botón derecho del ratón en el archivo AVI y **selecciona Abrir con.**_
*   _A continuación, selecciona Seleccionar otra aplicación y abre la lista de aplicaciones disponibles haciendo clic en Otras aplicaciones._
*   _En el último paso, **selecciona Examinar para buscar otra aplicación** en este ordenador e introduce la ruta de la carpeta donde está instalado el Reproductor de Windows Media. Ahora confirma su selección marcando Usar siempre esta aplicación para abrir archivos AVI y **haz clic en Aceptar.**_

#### Procedimiento para cambiar la aplicación por defecto en Mac OS

*   _Haz clic con el botón derecho del ratón en el archivo AVI y **selecciona Información.**_
*   _Buscar abrir con - Haz clic en el nombre si está oculto_
*   **_Selecciona el programa apropiado de la lista_** _y confirma haciendo clic en Cambiar para todos._
*   _Después de realizar los pasos anteriores, debería aparecer el siguiente mensaje: Este cambio se aplica a todos los archivos con extensión AVI. A continuación, **haz clic en Siguiente para completar la operación.**_

### Paso 4: Comprobar si el AVI tiene errores

¿Ha seguido todos los pasos del 1 al 3, pero el problema sigue produciéndose? Comprueba si el archivo es un verdadero archivo AVI. Es probable que el archivo esté dañado y, por lo tanto, ya no esté disponible.

#### 1\. El archivo AVI puede estar infectado con malware; compruébalo con un programa antivirus

Si el archivo AVI está infectado con un virus, puede ser la razón por la que no puede acceder a él. Comprueba si el archivo AVI y tu ordenador tienen algún tipo de malware o virus. ¿Está el archivo AVI infectado con malware? **Sigue los pasos sugeridos por tu programa antivirus**.

#### 2\. Asegúrate de que la extensión del archivo AVI está completa y sin errores

Si has recibido el archivo AVI problemático de un tercero, pídale que le proporcione otra copia. Al copiar el archivo pueden producirse errores que hagan que el archivo esté incompleto o corrupto. Esto puede causar problemas con el archivo.

El proceso de descarga de un archivo con extensión AVI puede detenerse y los datos contenidos en el archivo pueden no ser correctos. **Vuelve a cargar el archivo desde la misma fuente**.

#### 3\. Revisa de que tu cuenta tiene derechos de administrador

Algunos archivos requieren altos derechos de acceso para abrirlos. Salte de tu cuenta actual y **entra en una cuenta con permisos suficientes**. A continuación, abre el archivo de formato de intercalación de audio y vídeo.

#### 4\. Comprueba si el dispositivo cumple los requisitos para abrir el reproductor de Windows Media

Si tu sistema no tiene suficientes recursos para abrir los archivos AVI, **intenta cerrar todas las aplicaciones activas** y vuelve a intentarlo.

#### 5\. Rectifica de haber instalado las últimas actualizaciones del sistema operativo y de los controladores

Las últimas versiones de software y controladores ayudarán a resolver los problemas con los archivos Audio Video Interleave Format y a mantener a salvo tu dispositivo y sistema operativo. Los controladores o el software no actualizados pueden impedirle utilizar el dispositivo que necesita para procesar sus archivos AVI.
