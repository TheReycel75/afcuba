# Te estás confundiendo: conoce las diferencias entre software libre y Open Source  

Hay dos componentes clave en torno a los que gira el comportamiento y modos de uso de nuestro ordenador, el hardware y el software. A continuación, nos queremos centrar en el segundo de los apartados para que podamos distinguir entre dos conceptos que hemos escuchado muchas veces pero que en ocasiones confundimos.

En concreto nos referimos al **software libre y el Open Source** de los que tanto escuchamos hablar pero que quizá no diferenciamos bien en muchos casos. Lo cierto es que a priori todos distinguimos entre software de pago y gratuito, también conocido como privativo y no privativo. Y es que al hablar del software en general, al margen de tener en consideración el tipo de uso que vamos a hacer del mismo y para el que se ha diseñado, también miramos bien si tenemos que pagar o no por el mismo. De hecho, este es uno de los requisitos primordiales a la hora de descargarlo a nuestro equipo o buscar otro.

Incluso nos encontramos con algunos **títulos de pago** que podemos bajar y probar durante un determinado tiempo para después adquirir la licencia o suscribirnos pagando. Sin embargo, a la hora de distinguir el software libre de aquel denominado como Open Source, la cosa se complica un poco más. De Internet podemos descargar todo tipo de software, aunque las licencias con las que se nos ofrece varían sustancialmente. De ahí la importancia de distinguir entre estos dos conceptos que os comentamos que en muchas ocasiones nos llevan a error.

#### Qué es el software libre

Lo primero que debemos saber es que, al hablar de software libre, nos referimos a una licencia FSF o **Free Software Foundation**. Esta es una fundación creada en 1985 por Richard Stallman cuyo principal fin es promover el uso de este tipo de programas libres. En esta licencia se establecen cuatro reglas de uso.

*   Se puede usar con cualquier propósito.
*   Permite estudiar su funcionamiento y modificarlo adaptándolo a otros usos.
*   Se puede distribuir libremente para ayudar a otros.
*   Está permitida su mejora y hacer públicas estas para ayudar a la comunidad.

Eso sí, llegados a este punto debemos tener muy presente que, aunque cumpla las reglas mencionadas, no todo el software libre es necesariamente gratuito. Esto se debe a que puede conservar su carácter libre, pero **distribuirse de modo comercial**.

#### Diferencias principales con el Open Source

Aunque en un principio muchos piensen que es lo mismo, por otro lado, nos encontramos con el software conocido como Open Source o de código abierto. Y es que en el pasado 1998 algunos integrantes de la comunidad de software libre decidieron montar la OSI, también conocida como **Open Source Initiative**. Mientras que el software libre viene definido por cuatro puntos clave, aquí nos encontramos con un total de 10.

*   Código fuente accesible para otros.
*   Estas licencias deben permitir modificaciones y trabajos derivados.
*   La licencia no puede ser específica de un solo producto.
*   Esta licencia no puede restringir otras soluciones software.
*   No se puede añadir una licencia adicional en la redistribución del software.
*   No se puede restringir el acceso a ninguna iniciativa o empresa.
*   Mantener la **integridad del código fuente** en determinados casos.
*   No se puede discriminar a ninguna persona o grupo al acceder al código.
*   Redistribución libre.
*   La licencia debe ser tecnológicamente neutral en cuanto a su uso y funcionamiento.

Los derechos asociados a las licencias del Open Source deben aplicarse a todos a los que lo redistribuyan sin licencias adicionales.

Una vez revisado todo esto, podemos decir que la principal diferencia entre ambas modalidades es que el **código abierto es menos estricto** que el software libre. Podemos afirmar que todo software libre se podría definir como como de código abierto. Por el contrario, no todo el software Open Source tiene por qué ser libre.

En resumidas cuentas, podemos afirmar que el denominado como software libre se centra más en las cuestiones éticas del uso de programas. Por otro lado, el de código abierto prioriza el apartado técnico de la aplicación como tal y su crecimiento y mejora con el tiempo.

A modo de curiosidad, os diremos que, desde el punto de vista del mencionado Stallman, utilizar software Open Source no está asociado a que haya siempre libertad. Pero bien es cierto, admite, que se centra más en la disponibilidad a la hora de [acceder al código fuente](https://www.softzone.es/programas/lenguajes/editores-codigo-ruby/) del proyecto para mejorarlo.
