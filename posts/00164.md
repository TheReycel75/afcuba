# Ahorra datos móviles y batería con este sencillo truco para tu Xiaomi  

Puede que [MIUI](https://www.lavanguardia.com/andro4all/miui) no sea la capa de personalización de Android perfecta, pero es innegable que se trata de un software repleto de **características y opciones** que añaden valor a la experiencia con los móviles de Xiaomi, Redmi y POCO. En ocasiones, algunos de los [trucos escondidos en MIUI](https://www.lavanguardia.com/andro4all/xiaomi/los-mejores-18-trucos-para-moviles-xiaomi-exprime-miui-al-maximo) pueden ayudar a los usuarios a **ahorrar batería o reducir el consumo** de datos móviles.

Es el caso de una **opción poco conocida**, pero muy útil, que se puede encontrar en las últimas versiones de MIUI o MIUI for POCO, y de la que vamos a hablar en esta ocasión.

#### Haz que tu móvil Xiaomi ahorre datos cuando apagas la pantalla

La función en cuestión tiene un funcionamiento muy simple, pero extremadamente efectivo: **cuando apagas la pantalla del dispositivo y no lo estás usando,** pasado un tiempo **se desactivan automáticamente los datos móviles** para así ahorrar batería y reducir el consumo de datos.

Por defecto, la función viene desactivada, pero el proceso para habilitarla es extremadamente sencillo y bastan unos simples pasos. Está disponible en cualquier smartphone Xiaomi, Redmi o POCO con una versión reciente de MIUI, y estos son los pasos a seguir para poder activarla:

1.  Abre la aplicación de Ajustes de tu móvil Xiaomi, Redmi o POCO con MIUI
2.  Toca sobre "Batería"
3.  Desde ahí, toca el icono del engranaje situado en la esquina superior derecha
4.  Toca sobre "Desactivar datos móviles cuando el dispositivo esté bloqueado", y elige la opción de tiempo que desees

Cuando hayas terminado, verás cómo, cuando apagues la pantalla del móvil, pasado el tiempo especificado, **los datos móviles se desactivan**. Ten en cuenta que, mientras los datos estén deshabilitados, **no recibirás mensajes de texto ni notificaciones** de servicios de mensajería o redes sociales, a no ser que el dispositivo se encuentre conectado a una red Wi-Fi.
