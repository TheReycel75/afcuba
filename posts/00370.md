# Cómo saber si tu ordenador puede correr un juego  

Si quieres jugar a un videojuego en tu PC, pero no sabes si funcionará correctamente, te mostraremos cómo saber si tu ordenador puede correr un juego. **De este modo, no necesitarás arriesgar comprándolo o descargándolo sin certificar si funcionará sin parones o podrá ser ejecutado**. Esto te permite comprobar si aquellos lanzamientos, como Starfield, [que se convirtió en el juego más vendido de Steam antes de salir](https://www.lavanguardia.com/andro4all/juegos/starfield-aun-no-se-ha-estrenado-y-ya-es-el-juego-mas-vendido-en-steam), pueden ser jugados desde tu ordenador.

#### Comprueba si tu ordenador puede correr un juego con Can You Run It

La forma de averiguarlo es sencilla, rápida y gratuita. **Emplearemos una web llamada "Can You Run it" que nos informa sobre si nuestro ordenador está capacitado para ejecutar correctamente un videojuego**. El proceso resulta muy fácil, pero te lo explicaremos paso a paso.

### Cómo usar Can You Run it

Abajo de este párrafo dejamos el enlace de Can You Run It. Una vez entres, **introduce el nombre un juego en la barra situada en la esquina superior izquierda de la pantalla, aquella en la que pone "Search for a game"**. No es necesario que teclees todo el nombre, puedes ir escribiéndolo, ya que te aparecerá como sugerencia.

[Can You Run It](https://www.systemrequirementslab.com/cyri)

Una vez lo escribas, o selecciones desde las sugerencias, **pulsa el botón azul en el que pone "Can You Run it?"**. Comenzará un pequeño proceso, de varios pasos, en el que en el 3º paso deberás **descargar un archivo que rastrea las condiciones de tu ordenador**. Solo tendrás que instalarlo una vez, las siguientes veces que compruebes si un juego es capaz de funcionar correctamente en tu PC, no necesitarás reinstalarlo. **Esta apenas dura unos segundos** y, obviamente, es segura.

Finalmente obtendrás el informe final. Este es intuitivo, y también te indica qué le falta a tu PC para ejecutar correctamente ese videojuego, en el caso de que sea así. Se divide en 2 partes, **por un lado los requisitos mínimos y, por otro, los recomendados**. Si cumples los recomendados, también cumples los mínimos. Esto resulta lo más recomendable, aunque puedes jugar a un juego solo cumpliendo los mínimos. Si ni siquiera llega a los mínimos, el juego no funcionará en el PC.

Por ejemplo, **con Elden Ring cumplo los requisitos mínimos, pero no los recomendados, ya que mi RAM dedicada a vídeo es inferior a lo aconsejable**. En este caso podría jugarlo, aunque quizás no funcione tan bien como lo haría si cumpliese todos los aspectos recomendados.

Cambiar la RAM o la tarjeta gráfica es complejo y necesitarás trastear con el ordenador o que alguien lo haga por ti. Sin embargo, **cambiar el espacio no es tan difícil**, ya que si tienes poco espacio en tu ordenador, [puedes usar uno de estos servicios en nube](https://www.lavanguardia.com/andro4all/aplicaciones/los-7-mejores-servicios-de-almacenamiento-en-la-nube-de-2023-manten-tus-archivos-a-salvo), compatibles con móvil, y alojar allí fotos o vídeos para ahorrar espacio.

### Lista de juegos compatibles con tu ordenador

Otra opción para averiguar si un ordenador puede ejecutar un videojuego, es **ver la lista de títulos compatibles con mi PC**. Para ello vuelve al inicio de la página principal, desciende hasta el apartado How Many Games Can My Computer Run y pulsa en el botón azul en el que pone How many games can I run? Tras ello, aparecerá una lista con todos los videojuegos que están recogidos en la página, que son muchos, y al lado de estos, si cumples los requisitos mínimos y recomendados para ellos.

#### Otras páginas para saber si mi PC corre un juego

Can You RUN it no es la única web que te informa sobre esto, existen otras páginas para saber si tu PC corre un juego. Entre ellas **destacaremos a Can I Run It, sí, se llama prácticamente igual, y Game System Requirements**.

### Can I Run It

Esta web funciona de forma diferente a la que te hemos mostrado anteriormente. Entra desde el enlace inferior y selecciona la pestaña **¿Puedo correr un juego?** Selecciona el título del videojuego y serás redirigido a otra pantalla, desde la que **seleccionar el procesador, la tarjeta gráfica y la RAM**. Después de hacerlo, abajo se mostrará si cumples los requisitos mínimos y los recomendados.

[Can I Run It](https://technical.city/es/can-i-run-it)

### Game System Requirements

Para saber si tu ordenador puede ejecutar correctamente un videojuego desde Game System Requirements, entra en el enlace inferior, que te redirige al inicio de la web. **Desde allí selecciona uno de esos títulos o elige uno pulsando en la lupa de la esquina superior derecha**.

Sea cómo sea, cuando estés en el apartado del videojuego, aparecerán los requisitos mínimos. Si bajas, llegarás a uno llamado Can You Run It?, desde el que **introducir las especificaciones de tu ordenador, como su CPU, RAM o sistema operativo (OS), aunque resulta más rápido elegir directamente el modelo de PC**. Después pulsa en Compare para que se te indique si puedes correrlo.

[Game System Requirements](https://gamesystemrequirements.com/)
