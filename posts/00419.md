#### Conoce estas imprescindibles fórmulas de Excel

Desde realizar **operaciones matemáticas** simples hasta **buscar datos, realizar análisis financieros y gestionar fechas**, Excel ofrece una amplia gama de funciones y fórmulas que pueden ayudarte a automatizar tareas comunes y mejorar tu productividad. A continuación, te enseñaré algunas de las fórmulas más utilizadas para trabajar de manera más inteligente y efectiva en tu día a día.

*   **SUMA**: esta fórmula tiene la utilidad de realizar sumas de valores numéricos de manera rápida y sencilla. Esta función es esencial para calcular totales, sumar columnas o filas de números y obtener resultados precisos en hojas de cálculo. Se pueden hacer dos tipos de sumas: en primer lugar, de celdas determinadas usando la fórmula **\=SUMA(celda1;celda2;celda3)** para sumar tres celdas concretas; y, por otro, se puede sumar por rangos, es decir, una lista de celdas en una columna, en una fila o en un rango más amplio usando **\=SUMA(celda1:celda13)**

![](https://images.weserv.nl/?url=https%3A%2F%2Fcdn.andro4all.com%2Fandro4all%2F2023%2F10%2Fexcel-sum.jpg&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

Puedes sumar una fila, columna o una tabla entera.

*   **PROMEDIO**: esta es utilizada para calcular el promedio de un conjunto de números. Su utilidad radica en obtener rápidamente la media de un conjunto de valores, lo que es especialmente útil en análisis de datos, estadísticas y en la toma de decisiones basadas en cifras. Su debe usar de esta forma **\=PROMEDIO(A1:A5)** para calcular el promedio entre las celdas A1 y A5. También se puede calcular el promedio de una tabla completa con **\=PROMEDIO(A1:D5)**

![](https://images.weserv.nl/?url=https%3A%2F%2Fcdn.andro4all.com%2Fandro4all%2F2023%2F10%2Fexcel-promedio.png&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

Calcula la media de una lista de celdas o una tabla completa.

*   **SI**: esta es una herramienta poderosa que te permite tomar decisiones basadas en condiciones específicas. Nos servirá para realizar acciones diferentes según si una afirmación o criterio es verdadero o falso. Esta fórmula es esencial para la automatización de tareas y la lógica condicional en las hojas de cálculo. Por ejemplo, para aplicar una condición de _SUSPENSO_ o _APROBADO_ a unas notas deberemos escribir la fórmula así: **\=SI(B5<5;"SUSPENSO";"APROBADO")**. De este modo, si la primera condición se cumple aparecerá en la celda _SUSPENSO_ y si no se cumple aparecerá _APROBADO_.

![](https://images.weserv.nl/?url=https%3A%2F%2Fcdn.andro4all.com%2Fandro4all%2F2023%2F10%2Fexcel-si.png&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

Esta es la fórmula condicional por antonomasia en Excel.

*   **CONTAR.SI**: se utiliza para contar el número de celdas en un rango que cumplan con un criterio o condición específica. Esta función es especialmente útil cuando deseas realizar un recuento basado en un conjunto de datos que cumple con ciertos criterios. Muy útil, por ejemplo, para contar la cantidad de productos que tienen un valor por debajo de cierta cifra o cuántos alumnos tienen una media de nota inferior a una cifra específica. Se utiliza de este modo: **\=CONTAR.SI(rango; "criterio")**; por ejemplo, **\=CONTAR.SI(B2:F12; "4")** para saber cuántas veces se repite el número 4 en ese rango de celdas.

![](https://images.weserv.nl/?url=https%3A%2F%2Fcdn.andro4all.com%2Fandro4all%2F2023%2F10%2Fexcel-contar-si.png&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

Cuenta la cantidad de veces que se repite un valor o una palabra en una tabla o rango de celdas.

*   **DIAS** y **AHORA**: la fórmula DIAS se utiliza para calcular la diferencia en días entre dos fechas. Esta fórmula es útil en una variedad de situaciones, como **seguimiento de plazos, cálculo de antigüedad o planificación de eventos**. Por otra parte, AHORA se usa para mostrar la fecha actual cada vez que se abre la hoja de Excel. Ambas son muy útiles para medir los días que ha pasado desde un determinado evento. La fórmula AHORA se escribe tal que así: **\=AHORA()**. Por otro lado, si usas la fórmula DIAS para medir la cantidad de días que hay entre una celda y otra donde aparecen fechas, tan solo debes usar **\=DIAS(B5; E1)**, donde en E1 he introducido la fórmula AHORA para calcular **cuántos días han pasado desde la primera fecha hasta el día de hoy**.

![](https://images.weserv.nl/?url=https%3A%2F%2Fcdn.andro4all.com%2Fandro4all%2F2023%2F10%2Fexcel-dias-ahora.png&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

Ten tu documento actualizado nada más abrirlo con estas fórmulas.

*   **ESPACIOS**: se utiliza para eliminar espacios en blanco adicionales en una cadena de texto, dejando solo un espacio entre palabras. Esta fórmula es útil cuando trabajas con datos importados o cuando necesitas limpiar y formatear texto de manera consistente. Es muy sencilla de usar: **\=ESPACIOS(celda)**, por ejemplo, **\=ESPACIOS(B3)**

![](https://images.weserv.nl/?url=https%3A%2F%2Fcdn.andro4all.com%2Fandro4all%2F2023%2F10%2Fexcel-espacios.png&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

Elimina lo que sobra de un largo texto en segundos.

*   **SUSTITUIR**: tiene la utilidad de reemplazar un conjunto específico de caracteres o texto por otro dentro de una celda. Es una herramienta muy útil para la limpieza de datos, la edición de texto y la corrección de errores en tus hojas de cálculo. Se utiliza escribiendo **\=SUSTITUIR(celda;"texto\_a\_buscar";"nuevo\_texto")**. Por ejemplo, para sustituir la palabra "casa" por "fijo" de un listado de contactos puedes usar **\=SUSTITUIR(celda;"casa";"fijo")**

![](https://images.weserv.nl/?url=https%3A%2F%2Fcdn.andro4all.com%2Fandro4all%2F2023%2F10%2Fexcel-sustituir-extension-y-texto.jpg&output=jpg&bg=white&default=te.legra.ph/file/47739019e1308864fdca0.png)

Podrás eliminar de varias celdas una parte usando un espacio como texto final.
